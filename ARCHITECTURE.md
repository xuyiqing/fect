## Overview

fect is an R package for estimating causal effects in panel data using counterfactual imputation methods (Fixed Effects Counterfactual Estimators). It targets causal panel analysis with binary treatments under the parallel trends assumption, supporting treatment switching and limited carryover effects. The core abstraction is counterfactual imputation: impute missing potential outcomes Y(0) for treated units using control units, then compute the Average Treatment Effect on the Treated (ATT) as the gap between observed and imputed outcomes. The package is an R/C++ hybrid using Rcpp and RcppArmadillo for numerically intensive linear algebra (SVD, EM iterations, matrix factorization). Key external dependencies include fixest (initial FE regression and within-transformation of covariates), ggplot2 (visualization), doParallel/doFuture/future.apply (parallel bootstrap), MASS (generalized inverse), and mvtnorm (multivariate normal draws). Estimation methods include FE (fixed effects), IFE (interactive fixed effects / factor model), MC (matrix completion via nuclear norm regularization), CFE (complex fixed effects with structured covariates), the gsynth estimator (factors from never-treated units), and wrappers for modern DID estimators. Version 2.4.6 (development). References: Liu, Wang, and Xu (2024); Chiu et al. (2026).

## Architectural Patterns

- **S3 Dispatch with Formula Interface**: `fect()` uses `UseMethod()` to support both formula and direct (Y, D, X) interfaces. `fect.formula()` reads the formula into variable names with `.fect_formula_names()`, which accepts only column names (plus ignored intercept terms), and `fect.default()` does the computation. Same pattern for `interFE()`. Since 2.4.6, a formula and `X` cannot both be given.

- **R/C++ Layered Computation**: All numerically intensive operations (SVD, EM iterations, demeaning, matrix factorization) are implemented in C++ via RcppArmadillo. R handles data wrangling, parameter validation, control flow, and result assembly. The boundary is at the estimation functions: R `fect_fe()` calls C++ `inter_fe_ub()`.

- **Method-Agnostic Pipeline**: `fect.default()` provides a single preprocessing, CV, estimation, inference, diagnostics pipeline. Method-specific logic is encapsulated in `fect_fe()`, `fect_mc()`, `fect_cfe()`, `fect_nevertreated()`. Adding a new estimation method requires only a new estimation function and a routing entry.

- **Matrix-Oriented Data Representation**: Panel data is converted from long-form data frames to T x N matrices early in `fect.default()`. Covariates become T x N x p arrays. All downstream computation operates on these matrix forms, enabling efficient C++ computation.

- **Covariates Checked Before Estimation (2.4.6)**: After all unit and period removals, `.fect_check_covariates()` examines the covariates on the cells used to fit the model: it removes the specified fixed effects (with `fixest::demean()`), drops covariates with no variation, absorbed by the fixed effects, or linearly dependent on earlier ones (pivoted QR, the rule `lm()` uses), and warns once. Everything downstream (fits, CV, bootstrap, loo refits) sees the reduced covariate array, so estimates equal those of the fit without the dropped columns; `.fect_restore_covariates()` puts NA rows back at the output stage. As a second guard, the C++ `XXinv()`/`wXXinv()` switch to a pseudo-inverse when X'X is singular.

- **One Estimator per `time.component.from` (2.4.6)**: With never-treated fitting, the point fit, the case-bootstrap and jackknife replicates, the parametric replicates and the loo refits all use `fect_nevertreated()`. `fect_boot()` relabels ife/fe + never-treated as the gsynth estimator (when there is no CV; CV fits are already routed by `fect_cv()`), and its non-parametric replicate function has a never-treated CFE branch.

- **Replicate-Cell Mapping for Post-hoc Estimands (2.4.6)**: Bootstrap replicate b stores its units in its own order (`colnames.boot[[b]]`: the drawn unit indices for the case bootstrap, treated units first for the parametric bootstrap). `.po_replicate_cells()` maps a cell mask of the original panel into each replicate through that order, so a unit drawn twice contributes twice and an undrawn unit not at all. With the cluster bootstrap, replicate arrays have varying widths and are NA-padded by `.fect_store_slice()`; readers slice each replicate to `length(colnames.boot[[b]])`.

- **Failed Replicates Are Dropped and Counted (2.4.6)**: Replicate functions validate their result with `.fect_boot_result_ok()`, and the collectors run inside `tryCatch()`, filling a failed slot with the fields of `make_boot_na()`. The existing `boot.rm` step drops those replicates, and `fect()` reports how many were dropped (a warning when fewer than two remain).

- **Two-Tier Tolerance**: Cross-validation uses a looser tolerance (`max(tol, 1e-3)`) for speed during hyperparameter search, while final estimation uses the user-specified tolerance for precision.

- **Parallel Bootstrap via foreach with PSOCK Retry**: `fect_boot()` uses `foreach` with `doParallel`/`doFuture` backends for parallel bootstrap replication. The shared `.fect_make_future_cluster()` helper (in `cv-helpers.R`) builds PSOCK clusters that propagate `.libPaths()` to workers. Workers load fect from the library (not from `load_all()`), so parallel runs need an installed build of the same commit. A retry-with-backoff loop re-submits failed bootstrap draws through a reduced-worker cluster, falling back to sequential execution for any remaining failures.

- **Counterfactual Imputation as Core Abstraction**: All methods share the same conceptual framework: impute Y(0) for treated units using untreated observations, compute ATT as the gap. FE uses additive fixed effects, IFE adds latent factors (F * L'), MC uses nuclear norm regularization, CFE adds structured covariates.

- **Never-Treated vs Not-Yet-Treated Estimation Samples**: "notyettreated" includes not-yet-treated observations (requiring EM for missing data); "nevertreated" uses only never-treated units to estimate time components and factors. `fect_nevertreated()` handles the latter, including the implied weights `wgt.implied` (Nco x Ntr; `t(lambda.co) %*% W = t(lambda.tr)`, Xu 2017) and the optional simplex bound on treated loadings.

- **Comprehensive Diagnostic Suite**: Built-in tests (F-test, TOST equivalence, placebo, carryover, leave-one-out and double leave-one-out pre-trends) allow users to check the parallel trends assumption. Sensitivity analysis via optional HonestDiDFEct integration.

- **Two-Tier Post-hoc Estimand Layer (v2.4.0)**: Alternative estimands (cumulative ATT, APTT, log-scale ATT, window-restricted ATT) are computed from the imputed potential outcomes rather than inside the fit. `imputed_outcomes()` returns the cell-level data as a long-form data frame with columns `id`, `time`, `event.time`, `cohort`, `treated`, `Y_obs`, `Y0_hat`, `eff`, `eff_debias`, `W.agg`. `estimand()` computes typed estimands (`type` in `"att"`, `"att.cumu"`, `"aptt"`, `"log.att"`) by `by` in `"event.time"`, `"cohort"`, `"calendar.time"`, `"overall"`. `effect()` and `att.cumu()` are soft-deprecated (v2.4.0) and still used by `estimand("att.cumu")`; since 2.4.6 the cumulative ATT is the running sum of the per-period ATTs in all three (`att.cumu(weighted = TRUE)` keeps the older count-weighted version).

- **Rolling-Window Cross-Validation (v2.3.0)**: The default CV method is rolling-window masking (`cv.method = "rolling"`, `cv.prop = 0.1`, `k = 20`), which excludes each sampled unit's held-out block and all later observations from training. The 1-SE rule is the default selection rule (`cv.rule = "1se"`). The standalone `r.cv.rolling()` export exposes rolling CV outside of `fect()`.

- **Per-Role Weight Arguments (v2.3.1) and Modern Visual Defaults (v2.3.2)**: `W.est` and `W.agg` split the single `W` argument into outcome-model fit weights and ATT aggregation weights (`W` sets both). Since 2.4.6 the fit stores the aggregation weights as a T x N `W.agg` matrix when they weight the averages, and `W.agg` given alone stays out of the never-treated fit and its CV. `plot.fect()` and `esplot()` use a modern visual default; `legacy.style = TRUE` restores the classic style.

## Notes

- FE is internally treated as IFE with `r = 0` (zero latent factors). The code sets `method = "ife"` when `method = "fe"` and `r = 0`.
- The `gsynth` method forces `time.component.from = "nevertreated"` and `em = FALSE`, matching the gsynth package. Since 2.4.6, `method = "ife"` or `"fe"` with `time.component.from = "nevertreated"` and `se = TRUE` is fitted and resampled as the gsynth estimator, and its `method` slot reads `"gsynth"`.
- `boot.R` (5,099 lines) and `plot.R` (5,311 lines) are the two largest files. Both could benefit from modular decomposition in future refactors.
- The `binary` option (probit models) is only available with `method = "ife"` and has dedicated C++ implementations (`binary_qr.cpp`, `binary_svd.cpp`, `binary_sub.cpp`). At 2.4.6 `binary = TRUE` fails in `BiInitialFit()` (a pre-existing bug, not fixed in the 2.4.6 correctness run).
- The package uses `fixest::feols()` for initial OLS regression to obtain starting values, and `fixest::demean()` for the covariate rank check.
- `R/polynomial.R` and the `sfe` argument were removed in 2.4.5.
- Vignettes are a Quarto book (`vignettes/_quarto.yml`) with 11 numbered chapters: getting started, FE, alternative estimands, IFE/MC, CFE, gsynth, inference, heterogeneous effects, panel diagnostics, sensitivity analysis, plots; plus a cheatsheet, the changelog and references. `vignettes/_common.R` runs `devtools::load_all("..")` when the book is rendered inside the source tree.
- 10 bundled datasets (`simdata`, `sim_base`, `sim_gsynth`, `sim_linear`, `sim_region`, `sim_trend`, `turnout`, `gs2020`, `hh2019`, `simgsynth`) support examples and testing.
- 14 exported functions and 8 S3 methods registered in NAMESPACE. New internal helpers from the 2.4.6 correctness run: `.po_replicate_cells()`, `.po_mean_or_na()`, `.po_agg_weights()` (po-estimands.R); `.fect_resample()`, `.fect_store_slice()`, `.fect_boot_result_ok()` (boot.R); `.fect_nt_cv_skip_message()` (fect_nevertreated.R); `.fect_formula_names()`, `.fect_check_covariates()`, `.fect_restore_covariates()` (support.R); `xx_keep_inverse()` and `XX_RCOND_MIN` (auxiliary.cpp, file-local). None is exported.
- Total R source: 34,729 lines across 36 files. Total C++ source: 4,924 lines across 11 files (plus header).

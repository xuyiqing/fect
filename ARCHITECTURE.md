## Overview

fect is an R package for causal panel analysis with binary treatments under parallel trends
(Fixed Effects Counterfactual Estimators). Its core abstraction is counterfactual imputation: fit an
outcome model on untreated cells, impute the missing potential outcomes Y(0) of treated cells, and
average the gaps Y - Y(0) into the ATT and its by-period, by-cohort and cumulative summaries. The
package is an R/C++ hybrid: R (`R/`, 38 files, about 37,300 lines) does input handling, data
reshaping, cross-validation, inference and output; C++ via Rcpp and RcppArmadillo (`src/`, 11 files
plus a header, about 5,000 lines) does the linear algebra (SVD, EM iterations, demeaning, factor
extraction). Estimators: two-way FE, interactive fixed effects (IFE, and gsynth, its never-treated
form), matrix completion (MC) and complex fixed effects (CFE). Inference: unit (cluster) bootstrap,
jackknife, a parametric bootstrap for the gsynth setting, and (2.4.9) conformal intervals from
leave-one-control-out fits (`vartype = "conformal"`, no resampling). Post-hoc estimands (cumulative ATT,
APTT, log-ATT) are computed from the saved replicate draws. Key dependencies: fixest (initial
fits, covariate demeaning), MASS (`ginv`), future / doFuture / doRNG / foreach (parallel
bootstrap), ggplot2 and GGally (plots), mvtnorm (parametric errors). Version 2.4.9 (unreleased; 2.4.8 and 2.4.7 were development versions and are part of it).

> With a unit effect (`force` 1 or 3) `.solve_bounded_loading_int(intercept = TRUE)` centres the unit's

> and returns its list, with no resampling. For each
> never-treated control `.conformal_fold()` builds a background of the other controls and fits the
> predictions of the treated units and of the control (shown only the treated unit's pre-treatment
> window) against it, with the point fit's tuning. `gsynth` makes one component fit per fold; `ife`

> which sorts the endpoints at the `q` returned by `.conformal_q()` and computes the dual p-value.

## Contracts introduced in 2.4.9

### Conformal intervals (`vartype = "conformal"`, `R/conformal.R`)

- **Pool by observation pattern only.** A control is in the pool of a treated cell iff it is eligible
  for the treated unit's window (observed at every pre-treatment date the treated unit is observed)
  and observed at the date. For an aggregate it must be in the pool of every aggregated cell. The pool
  is fixed before any fit is looked at. Controls outside it are not used and are counted in
  `n.excluded`; `N` is the pool size plus one.
- **A failed fold keeps its slot.** A pool control whose component fit returns `NULL`, or whose
  prediction or error is not finite, has `a = -Inf` and `b = +Inf`. `N` and `q` do not change, the
  interval is widened or unchanged, never shortened, and with at least `q` failed slots it is the
  whole real line. The p-value counts only strict tail violations, so a failed slot never adds to a
  count and the p-value stays dual to the interval. A fit that stops at `max.iteration` is used as it
  is and is not failed.
- **Counts.** `n.failed` (per interval) counts failed pool slots. `n.failed.folds` (overall) is the
  number of controls with a failed component fit or a non-finite in-pool slot, so the status note and
  the warning never say 0 while an interval is widened. `n.failed.fits` counts component fits that
  returned `NULL`. `n.intervals.affected` counts rows of `conformal$unit` with `n.failed > 0`.
- **One calibration convention.** `q = max{q in 0..floor(N/2) : q = 0 or fl((2q - 1)/N) <= gamma}`,
  compared in double precision with no tolerance. `.conformal_interval()` computes the p-value with the
  same division and the same comparison, so `p <= gamma` iff 0 is outside the effect interval, for
  `0 < gamma < 1`. `fect.default()` stops when `alpha` is not a single number in `(0, 1)`. `fect` builds
  no other alpha on this path: `est.att90` and `att.bound` use `2 * alpha`, which is exact in binary,
  and `level = 1 - alpha` is stored metadata only. A caller who passes a computed alpha (`1 - 0.9`)
  gets that value's q.
- **Tuning is frozen.** `r`, `lambda`, `force`, covariates, `tol` and `max.iteration` come from the
  point fit; no fold cross-validates. The finite-sample guarantee needs the tuning not to depend on
  which unit is treated, which holds when it is fixed in advance (`CV = FALSE`).
- **What is claimed, and what is not.** For one treated unit and one date, coverage is at least
  `1 - (2q - 1)/N` if the pool controls' and the treated unit's errors are exchangeable given the
  observation pattern, the failure rule is valid relative to a finite reference completion, and the
  tuning is symmetric across units. `fect` checks none of this. Coverage for `est.att`, `est.avg`,
  `est.avg.unit` and the calendar-time ATT is not established by the unit-level theorem.
- **Scope.** Options without a conformal version stop in `fect.default()`; post-hoc functions that need
  draws stop through `.fect_stop_if_conformal()`; the equivalence plot stops in `plot.fect()`.
- **No bootstrap objects.** A conformal fit has no `boot.diag` and no draws; `fect_boot()` returns
  before any resampling. For `method = "ife"` the `convergence` slot is the point fit's.
- **Numbers.** For a fit with no failed fold and no `alpha` within `1e-10` below a cutoff, every number
  equals the one the implementation before this convention gave (commit e99f2d2).

## Contracts introduced in 2.4.8

### Bounded loadings and the intercept (`loading.bound = "simplex"`)

- **Shift invariance.** Bounded fits are invariant to adding a constant to a treated unit's outcome
  when `force` has a unit effect (`force = "unit"` or `"two-way"`): the loadings, the simplex
  weights (`wgt.implied`), the CV-chosen `gamma.loading`, `loading.proj.resid` and the ATT do not
  change, and that unit's `alpha.tr` moves by the constant. This holds to floating point (the tests
  check 1e-8; the typical difference is below 1e-12). It does not hold without a unit effect
  (`force = "none"` or `"time"`): there is no intercept to absorb the level.
- **Joint minimiser.** For each treated unit the code returns the minimiser of
  `(1/gamma) KL(w || q) + || u - alpha 1 - F Lambda_co' w ||^2` over `alpha` and the simplex weights
  `w`, where `u` is the unit's residual after the grand mean, the covariates and the time effects,
  `F` the estimated factors at the unit's training periods and `q` the uniform reference. `alpha` is
  profiled out: the profiled problem is the 2.4.7 problem on `u` and `F` centred over the unit's own
  training periods, with the same `gamma`. The intercept is not bounded.
- **Which periods are centred.** Balanced panels: the common pre-treatment window. Unequal windows:
  the unit's own window. Missing cells: the unit's observed pre-treatment periods
  (`time.pre[[i]]`). In the gamma CV: the training folds only, never the held-out periods.
- **Solver.** With an intercept the centred problem is solved by Newton's method on the dual, whose
  answer does not depend on an iterative solver's stopping rule; L-BFGS-B (then mirror descent) is the
  fallback when Newton does not converge. Known limit: in a test of 3,360 random problems, 4 at
  `gamma = 1e6` used the fallback; they are never worse than 2.4.7's solution, and their loadings are
  shift-invariant to 2.1e-8 at worst, above the 1e-8 target.
- **Unchanged.** `loading.bound = "none"`, and `force = "none"` or `"time"` with `"simplex"`
  (byte-identical to 2.4.7 for a fixed `gamma.loading` and for CV with the same seed).
- **Outputs that change values with a unit effect.** `lambda.tr`, `alpha.tr`, `eff`, the ATT slots,
  `wgt.implied`, `loading.proj.resid` (now the norm of the joint-fit residual), and the `gamma.loading`
  that CV picks. The slot layout is unchanged.

### F test with one treated unit or one period (#179)

`diagtest()` computes the small-sample factor `scale = (N_bar - q) / ((N_bar - 1) q)` with `q` the
number of periods in the window. It is 0/0 when `N_bar = 1`, and a one-period window (`pre.periods = 0`
or `-1`) reaches the same case. Both branches now treat a non-finite or non-positive `scale` as too few
treated units: `f.stat`, `f.p` and `f.equiv.p` are `NA`, with the message "Can't calculate the F
statistic because of insufficient treated units." The fit continues.

### did 2.5.1 gate (#178)

`did_wrapper(method = "cs_never")` and `"cs_notyet"` stop with a message naming did 2.5.1 when an older
did is installed. DESCRIPTION lists `did (>= 2.5.1)` under Suggests.

## Contracts introduced or tightened in 2.4.7

### keep.sims arrays and `colnames.boot`

With `keep.sims = TRUE`, `fect_boot()` stores `eff.boot`, `D.boot`, `I.boot` as `TT x W x B` arrays and
`colnames.boot` as a list of length `B`.

- `colnames.boot[[b]]` holds the original column positions (1..N) of replicate b's units, in the
  order of the replicate's columns. Case bootstrap: the drawn units (a unit drawn twice appears
  twice). Parametric: `c(id.tr, fake.co)`, treated units first. Jackknife: `(1:N)[-j]`.
- `W = N` for the case and parametric bootstraps, `N - 1` for the jackknife. For the cluster
  bootstrap, replicates have varying width; `.fect_store_slice()` pads each slice with NA to the
  widest replicate (widening the array when needed; an all-NA failed replicate never widens it).
  `length(colnames.boot[[b]])` is replicate b's real width.
- Readers must map through `colnames.boot`: `.po_replicate_cells()` (estimand, imputed_outcomes),
  `effect()` (slices to the real width), `.validate_po_contract()` (accepts `W > N` only with
  `colnames.boot`). `plot.R`'s parametric `id` path reads the first `Ntr` columns, which is correct
  because parametric replicates put the treated units first.
- `B` is the number of replicates kept: failed replicates are removed by `boot.rm`, and a message
  reports `k of B ... replicates failed and were dropped`.

### Estimand replicate alignment

`.po_replicate_cells(fit, cell_mask, b)` takes a `TT x N` logical mask in original coordinates and
returns replicate b's draws for those cells (`eff`) and their source cells (`orig`, linear indices
into `Y.dat`, `D.dat`, ...). A unit drawn k times contributes k copies; an undrawn unit none. Every
non-jackknife replicate path uses it: overall and event-time ATT (via `.po_replicate_att()`),
APTT (per-replicate numerator and denominator), log-ATT (per-cell instability share), and
`imputed_outcomes(replicates = TRUE)`. Invariant: with the treated-cell mask, the per-replicate
mean (weighted by `W.agg[orig]` for a weighted fit, final W1) equals `att.avg.boot[b]`, so
`estimand(fit, "att", "overall")$se` equals `est.avg`'s SE, weighted or not. Jackknife paths keep
their own column-drop mapping; the jackknife overall ATT reads `att.avg.boot` (final J2).

### Input validation layer

All checks run in `fect.formula()` / `fect.default()` before any reshaping, except the rank check,
which needs the estimation cells and so runs at step 7b. Each stop is `call. = FALSE` and names the
offending term, column or unit. `interFE()` shares the formula parser and the `X` rule but keeps
its own absorbed-covariate stops (no drop policy there). Final S5 adds two of them: a covariate
that does not vary under `force = "none"` (the intercept absorbs it) and one that is a unit-level
plus a period-level variable under `force = "two-way"`, with the tolerances of
`.fect_check_covariates()` and only for covariates whose values are all finite.

### Covariate rank check (step 7b)

`.fect_check_covariates(X, M.est, force, Xname, extra.fe)`: `M.est` is the untreated observed cells
(`II == 1`), restricted to never-treated units when `time.component.from = "nevertreated"`. Order of
checks: (1) no variation on `M.est` (centred norm <= 1e-12 x max(1, norm)); (2) absorbed by the
model's fixed effects (norm after `fixest::demean()` <= 1e-8 x centred norm; the fixed effect is
named when unit or time alone absorbs it; cfe extra fixed effects included); (3) aliased among the
rest (`qr(tol = 1e-7)` pivots, keeping the earlier column as `lm()` does). Dropped covariates are
removed from `X` before the main fit, CV, bootstrap, loo refits, permutation and dloo, so estimates
equal those of the fit without them; `.fect_restore_dropped_covariates()` re-inserts NA rows at
output. The C++ guard below is a second line for rank-deficient X'X that this check cannot see, such
as a bootstrap replicate whose covariates happen to be collinear. Fits whose X'X has full rank after
scaling its columns take the old code path byte for byte, whatever the covariates' units.

### C++ guard for X'X (`XXinv()`, `wXXinv()`; C5, C5b)

Every C++ core that estimates covariate coefficients (fe, ife, gsynth, mc, cfe, the binary cores;
main fit and every replicate) inverts X'X through `XXinv()` or its weighted twin `wXXinv()`.

1. X'X is built exactly as at 412d7ae. If it has a non-finite entry, it is inverted as at 412d7ae.
2. `xx_scaled_ok()` scales it to unit diagonal: `xs = D X'X D`, `D = diag(1 / sqrt(diag(X'X)))`
   (the correlation-scaled X'X). An all-zero covariate gets scale 1, so its row and column of `xs`
   stay 0.
3. If every diagonal entry of X'X is positive and `rcond(xs) > 1e-12`, the unscaled X'X is inverted
   with `inv()` (`XXinv()`) or `inv_sympd()` (`wXXinv()`), as at 412d7ae.
4. Otherwise (exact or near-exact collinearity, or an all-zero covariate) the result is
   `D pinv(xs) D`: a symmetric generalized inverse G of X'X (`X'X G X'X = X'X`), with a zero row
   and column for an all-zero covariate. At 412d7ae, `inv()` on such a matrix either stopped with
   "inv(): matrix is singular" or returned an inaccurate inverse that changed the estimates.

The test is on `xs`, not on X'X, because the rcond of the raw X'X depends on the covariates' units:
two columns whose scales differ by a factor s give an rcond of about 1/s^2. A test on the raw X'X
treats a full-rank fit with one covariate in large units (GDP in dollars, x 1e8) as singular, and
`pinv()` then zeroes the small-scale covariate. The first version of this guard did that (reviewer
STOP, fixed as C5b); keep any new trigger unit-free.

### Shared collector loop (R/boot.R)

The serial path only fills `boot.out[[j]] <- one.nonpara(boot.seq[j])` in order (RNG use as
before); one loop after the `if (do_parallel_boot)` block stores every replicate for both paths.
Each replicate is stored inside `tryCatch`; if a result cannot be stored (odd shape), the replicate
is replaced by `make_boot_na()` and stored again (a second failure is a bug and re-raises). All
slots are written by index (`colnames.boot`, `eff.off.boot` are preallocated lists), so a replicate
can be rewritten safely. Add any new per-replicate slot inside this loop.

### Implied weights (`wgt.implied`)

`.fect_nt_implied_weights()` computes `ginv(t(Lco)) %*% t(Ltr)` = `Lco (Lco'Lco)^-1 Ltr'` (Xu 2017),
Nco x Ntr; the simplex path stores `t(W_tr)`, also Nco x Ntr. `fect.default()` sets dimnames
(control ids x treated ids). `t(lambda.co) %*% wgt.implied == t(lambda.tr)`; with time fixed
effects the unbounded columns sum to zero (control loadings are centred). NULL when r = 0. Since
2.4.8 the simplex weights come from the joint fit of the intercept and the loadings when `force`
has a unit effect (see "Contracts introduced in 2.4.8").

### cfe + never-treated replicates (follow-up B10-cfe)

The point fit of `method = "cfe"` with `time.component.from = "nevertreated"` is
`fect_nevertreated(method = "cfe")`, and so are its parametric refits (`impute_Y0()`). The
nonparametric `one.nonpara()` has a branch for the same case, placed before the plain `cfe` branch,
so case-bootstrap and jackknife replicates, including those inside the `loo` refits, use that
estimator too. The parallel loop's trimmed closure keeps `time.component.from`, which the branch
reads. `dloo = TRUE` with never-treated fitting stops in `fect.default()`'s argument checks, after
the `vartype` and `method` checks and before the bootstrap.

### Cumulative ATT (follow-up B11)

At event time k the cumulative ATT is the running sum of the per-period ATTs (`fit$att`) from the
window's first event time to k. `getEffect()` (so `effect(cumu = TRUE)` and
`estimand("att.cumu", "event.time")`) and `att.cumu.sub()` (so `att.cumu()` with its default
`weighted = FALSE` and `estimand("att.cumu", "overall")`) compute it the same way for the point
estimate and for each replicate. A replicate with no treated cell at one of the window's event times
gives NA and is dropped (`na.rm`) in both, so their bootstrap and parametric SEs agree.
`att.cumu(weighted = TRUE)` keeps the count-weighted number (L times the mean effect over the
window's treated cells) with its old replicate rescaling, identical to 5afa708 in the estimate.
Final J1 and S1: for jackknife fits both functions use `.jackknife_se()` (the Tukey SE of
`jackknifed()`, also with `weighted = TRUE`) with a normal interval and p-value, and for parametric
fits both use the normal interval. So `att.cumu()` and `effect()` agree in S.E., interval and
p-value for every variance type and in every row: since #153 `att.cumu()` builds its first row with
`att.cumu.sub()` too (it copied `fit$est.att`, the normal interval by default, while `effect()` took
quantiles), and `att.cumu.sub()` keeps the replicate matrices as matrices (`drop = FALSE`) for a window
of one event time.

### Aggregation weights `fit$W.agg` (follow-up B13)

`fect.default()` stores the TT x N aggregation weights as `output$W.agg` only when `W` or `W.agg`
weights the aggregation. Read it with `fit[["W.agg", exact = TRUE]]`: on a fit without the slot,
`fit$W.agg` partially matches the string slot `W.agg.col`. The estimators' own copy of the matrix
sits under the name "W", after the column-name slot of the same name, where extraction by name
cannot reach it; `.po_agg_weights()` falls back to it for fit objects made before the slot existed.

Final W1: `.po_agg_weights_or_null()` returns this matrix, or NULL for a fit made without `W` or
`W.agg` (then every path runs its old unweighted expressions, so those fits' numbers do not change).
Every cell-based `estimand()` path and `effect()` take weighted means, in the estimate and in each
replicate: a bootstrap or parametric draw takes the weight of its source cell (`W[rc$orig]`, through
`colnames.boot`), a jackknife replicate j the weights `W[, -j]`. This reproduces the fit's own
weighted `att`, `att.avg`, `att.boot` and `att.avg.boot`. `estimand(weights = )` accepts only NULL.

### `fect_mspe()` refits (final S2, S4)

For each fit, `fect_mspe()` hides the held-out cells in the data and refits with `.refit_fun()`:
`fect` for calls to `fect()` (or `fect.formula` / `fect.default`), otherwise the function named in the
stored call (gsynth stores its own call), found from the caller's frame with
`get0(mode = "function")`. The refit replays the call's arguments except `formula`, `data`, `index`,
`Y`, `D`, `X`, with `CV = FALSE`, `se = FALSE` and `r = r.cv`. Every expression of the call is
evaluated by `.eval_call_arg()` in `.call_envs()`: the frame `fect_mspe()` was called from, then the
environment of `fit$formula` (fect.formula fits store the formula). The data is
`fit[["data", exact = TRUE]]` when it is a data frame (gsynth stores it; `fit$data` would partially
match `data.long`), else the call's `data`. fect code never names gsynth. A fit made without a
formula inside one function and scored from another cannot be refitted; the error names the
argument. Nothing new is stored on fits.

#152: the data call is evaluated with `accept = is.data.frame`, so a function found under the data's
name (`df`, `data`) is skipped and the next environment is tried. #163: the refit is scored with
`.fect_heldout_pred()` (below), not with its `Y.ct.full`.

### Causal moderation model `est.cm` (final S3)

With `cm = TRUE`, `fect_fe()` fits a second model on the treated cells (`II.cm`) with the same `r`,
`force` and tolerance and returns it as `est.cm`, read by `fect_iden()` (`est.cm$fit`) and
`plot(type = "hte", cm = TRUE)`. `fect.default()` passes `cm` and `II.cm` on the `se = FALSE` path
too, and when the main model came from `fect_cv()`, which has no cm model, it fits the cm model once
more with `r.cv` and `boot = 0`. No replicate fits this model. `cm = TRUE` with
`time.component.from = "nevertreated"` stops in the argument checks.

### Contracts changed in the follow-up batch (fect #152-#161, #163)

- **Held-out prediction (#163).** `fect_mspe()` and `r.cv.rolling()` hide a cell by setting its outcome
  to NA and refitting. `fect()` drops that row and stores 0 for its covariates, and on the
  never-treated path `Y.ct.full` holds only the factor part (gsynth) or 0 (cfe) at control cells. Both
  scorers now call `.fect_heldout_pred(fit, rr, cc, newdata)` at the hidden cells only: the refit's
  fitted value with the covariates at 0 (`Y.ct.full`; never-treated path: `est$fit` for control units,
  `mu + alpha.tr + xi + F lambda.tr` for treated units) plus the cells' covariates from the scorer's
  data times `fit$beta`. No slot of any fit changes; scores and rolling-CV choices do. Limits: a CFE fit
  with extra `index` fixed effects puts a hidden cell in the pooled group of missing cells, so its
  prediction uses that group's effect; a never-treated cfe fit with Z, Q or extra fixed effects gets NA
  (not scored) at treated units' cells; a cell with a missing covariate gets NA (not scored).
- **Basic p-values of bootstrap fits (#158).** Under `ci.method = "basic"` every effect slot and
  `est.beta` of a bootstrap fit take `.pvalue_basic_dual()`, the p-value dual to the basic interval on
  the same type-7 quantiles, so `p < alpha` exactly when the `1 - alpha` interval excludes 0. `dloo`'s
  `pre.est.att` uses it too. Parametric fits keep `.pvalue.basic()`'s counting rule; `"normal"` slots
  keep the normal p-value, now also the subgroup switch-off effects.
- **`est.group.att` (#155).** Its interval and p-value follow `ci.method` like every other slot (the
  branches were swapped since v1.0.5).
- **Per-unit ATT (#156).** `att.avg.unit` (and its replicates, so `est.avg.unit`) averages each treated
  unit's effects over its observed treated cells, in `fe.R`, `cfe.R`, `mc.R`, `fect_nevertreated.R`
  and `cv.R`; a unit with no observed treated cell is NA and dropped from the mean.
- **`normalize = TRUE` (#157).** `fit$Y.dat`, `fit$est.cm` and the covariate array the estimator returns
  (the fit's second `X` element) are rescaled by `norm.para[1]` before output. The local `Y` and `X`
  stay normalized for the dloo overlay and the cm refit. Other normalized slots are unchanged (see
  Notes).
- **Weighted jackknife tests (#154).** `est.placebo` and `est.carryover` of weighted jackknife fits have
  the same 7 columns as unweighted fits (90% bounds from the jackknife SE).
- **Cumulative ATT rows (#153).** See "Cumulative ATT" above.
- **`estimand()` (#159, #161).** `ci.method = NULL` resolves to `"normal"` on a jackknife fit, whatever
  the type. `by` takes `"event.time"` and `"overall"` for `"att"` and `"att.cumu"`, `"event.time"` for
  `"aptt"` and `"log.att"`; other values stop through `.estimand_by_stop()`. `cells` works for `"att"`
  with `by = "overall"`; `"att.cumu"` takes `window` only (with `by = "overall"`) and stops on `cells`.
- **`binary = TRUE` (#160).** Stops in the `fect()` and `interFE()` generics.
- **`fect_mspe()` data lookup (#152).** See "`fect_mspe()` refits" above.

## Architectural Patterns

- **S3 dispatch with a formula interface**: `fect()` and `interFE()` dispatch to formula and default
  methods. The formula methods only parse (through the shared `.fect_formula_names()`) and call
  the default method with column names.
- **R/C++ layering**: numerically heavy steps (SVD, EM, demeaning) live in C++; R handles control
  flow, validation and output assembly. Guards against degenerate input exist on both sides (R rank
  check; C++ `panel_factor()` clamp and the `XXinv()` generalized-inverse fallback, whose trigger
  does not depend on the covariates' units).
- **Method-agnostic pipeline**: `fect.default()` runs one pipeline (validate, reshape, CV, fit,
  bootstrap, diagnostics, assemble); method-specific logic sits in `fect_fe()`, `fect_mc()`,
  `fect_cfe()` and `fect_nevertreated()`.
- **Matrix-oriented data**: panels become `TT x N` matrices and `TT x N x p` covariate arrays early;
  masks (`II`, estimation cells, treated cells) drive every later step.
- **Replicates addressed through a column map**: bootstrap replicates are refits on resampled panels;
  their columns are addressed through `colnames.boot`, never by the original positions. Arrays can be
  wider than N (cluster bootstrap), padded with NA.
- **Fail-soft replicates, loud main fits**: a replicate that fails or returns an odd shape is dropped
  and counted; the same condition in the main fit stops with a message that says what to change.
- **Serial and parallel twins share one collector**: only replicate generation differs between the
  serial loop and the parallel `foreach` / `future` path.
- **Resolved settings are stored on the fit**: `vartype`, `para.error`, `loading.bound`,
  `gamma.loading`, `method` (ife + never-treated reports `"gsynth"`), `remove.id`; post-hoc
  functions read these slots, not `x$call`.
- **Refits inherit the fit's settings**: CV, bootstrap replicates, parametric draws and loo refits
  receive the same `loading.bound`, `time.component.from`, `para.error` and weight roles as the main
  fit; `fect_mspe()` refits each fit with the function that made it (final S2).
- **Two-tier post-hoc estimand surface (v2.4.0)**: `imputed_outcomes()` (cell-level long form) and
  `estimand()` (typed dispatcher); `effect()` / `att.cumu()` are soft-deprecated and back
  `estimand("att.cumu")`. Post-hoc summaries weight and form intervals as the fit's own slots do
  (final W1, J1, J2, S1).
- **Rolling-window CV and the 1-SE rule (v2.3.0)**: default CV design and selection rule;
  `criterion = "pc"` bypasses the rule and picks the lowest PC.
- **Per-role weights (v2.3.1)**: `W.est` (fit) and `W.agg` (aggregation); since this run `W.agg`
  never reaches the fit or the CV scores, and weights reach the parametric bootstrap. The
  follow-up stores the aggregation weights on the fit as `W.agg` (B13).

## Overview

fect is an R package for causal panel analysis with binary treatments under parallel trends
(Fixed Effects Counterfactual Estimators). Its core abstraction is counterfactual imputation: fit an
outcome model on untreated cells, impute the missing potential outcomes Y(0) of treated cells, and
average the gaps Y - Y(0) into the ATT and its by-period, by-cohort and cumulative summaries. The
package is an R/C++ hybrid: R (`R/`, 36 files, about 34,500 lines) does input handling, data
reshaping, cross-validation, inference and output; C++ via Rcpp and RcppArmadillo (`src/`, 11 files
plus a header, about 5,000 lines) does the linear algebra (SVD, EM iterations, demeaning, factor
extraction). Estimators: two-way FE, interactive fixed effects (IFE, and gsynth, its never-treated
form), matrix completion (MC) and complex fixed effects (CFE). Inference: unit (cluster) bootstrap,
jackknife, and a parametric bootstrap for the gsynth setting. Post-hoc estimands (cumulative ATT,
APTT, log-ATT) are computed from the saved replicate draws. Key dependencies: fixest (initial
fits, covariate demeaning), MASS (`ginv`), future / doFuture / doRNG / foreach (parallel
bootstrap), ggplot2 and GGally (plots), mvtnorm (parametric errors). Version 2.4.7 (unreleased).

## Contracts introduced or tightened in 2.4.7

### keep.sims arrays and `colnames.boot`

With `keep.sims = TRUE`, `fect_boot()` stores `eff.boot`, `D.boot`, `I.boot` as `TT x W x B` arrays and
`colnames.boot` as a list of length `B`.

- `colnames.boot[[b]]` holds the original column positions (1..N) of replicate b's units, in the
  order of the replicate's columns. Case bootstrap: the drawn units (a unit drawn twice appears
  twice). Parametric: `c(id.tr, fake.co)`, treated units first. Jackknife: `(1:N)[-j]`.
- `W = N` for the case and parametric bootstraps, `N - 1` for the jackknife. For the cluster
  bootstrap, replicates have varying width; `.fect_store_slice()` pads each slice with NA to the
  widest replicate (widening the array when needed; an all-NA failed replicate never widens it).
  `length(colnames.boot[[b]])` is replicate b's real width.
- Readers must map through `colnames.boot`: `.po_replicate_cells()` (estimand, imputed_outcomes),
  `effect()` (slices to the real width), `.validate_po_contract()` (accepts `W > N` only with
  `colnames.boot`). `plot.R`'s parametric `id` path reads the first `Ntr` columns, which is correct
  because parametric replicates put the treated units first.
- `B` is the number of replicates kept: failed replicates are removed by `boot.rm`, and a message
  reports `k of B ... replicates failed and were dropped`.

### Estimand replicate alignment

`.po_replicate_cells(fit, cell_mask, b)` takes a `TT x N` logical mask in original coordinates and
returns replicate b's draws for those cells (`eff`) and their source cells (`orig`, linear indices
into `Y.dat`, `D.dat`, ...). A unit drawn k times contributes k copies; an undrawn unit none. Every
non-jackknife replicate path uses it: overall and event-time ATT (via `.po_replicate_att()`),
APTT (per-replicate numerator and denominator), log-ATT (per-cell instability share), and
`imputed_outcomes(replicates = TRUE)`. Invariant: with the treated-cell mask, the per-replicate
mean equals `att.avg.boot[b]`, so `estimand(fit, "att", "overall")$se` equals `est.avg`'s SE for
unweighted fits. Jackknife paths keep their own column-drop mapping.

### Input validation layer

All checks run in `fect.formula()` / `fect.default()` before any reshaping, except the rank check,
which needs the estimation cells and so runs at step 7b. Each stop is `call. = FALSE` and names the
offending term, column or unit. `interFE()` shares the formula parser and the `X` rule but keeps
its own absorbed-covariate stops (no drop policy there).

### Covariate rank check (step 7b)

`.fect_check_covariates(X, M.est, force, Xname, extra.fe)`: `M.est` is the untreated observed cells
(`II == 1`), restricted to never-treated units when `time.component.from = "nevertreated"`. Order of
checks: (1) no variation on `M.est` (centred norm <= 1e-12 x max(1, norm)); (2) absorbed by the
model's fixed effects (norm after `fixest::demean()` <= 1e-8 x centred norm; the fixed effect is
named when unit or time alone absorbs it; cfe extra fixed effects included); (3) aliased among the
rest (`qr(tol = 1e-7)` pivots, keeping the earlier column as `lm()` does). Dropped covariates are
removed from `X` before the main fit, CV, bootstrap, loo refits, permutation and dloo, so estimates
equal those of the fit without them; `.fect_restore_dropped_covariates()` re-inserts NA rows at
output. The C++ guard below is a second line for rank-deficient X'X that this check cannot see, such
as a bootstrap replicate whose covariates happen to be collinear. Fits whose X'X has full rank after
scaling its columns take the old code path byte for byte, whatever the covariates' units.

### C++ guard for X'X (`XXinv()`, `wXXinv()`; C5, C5b)

Every C++ core that estimates covariate coefficients (fe, ife, gsynth, mc, cfe, the binary cores;
main fit and every replicate) inverts X'X through `XXinv()` or its weighted twin `wXXinv()`.

1. X'X is built exactly as at 412d7ae. If it has a non-finite entry, it is inverted as at 412d7ae.
2. `xx_scaled_ok()` scales it to unit diagonal: `xs = D X'X D`, `D = diag(1 / sqrt(diag(X'X)))`
   (the correlation-scaled X'X). An all-zero covariate gets scale 1, so its row and column of `xs`
   stay 0.
3. If every diagonal entry of X'X is positive and `rcond(xs) > 1e-12`, the unscaled X'X is inverted
   with `inv()` (`XXinv()`) or `inv_sympd()` (`wXXinv()`), as at 412d7ae.
4. Otherwise (exact or near-exact collinearity, or an all-zero covariate) the result is
   `D pinv(xs) D`: a symmetric generalized inverse G of X'X (`X'X G X'X = X'X`), with a zero row
   and column for an all-zero covariate. At 412d7ae, `inv()` on such a matrix either stopped with
   "inv(): matrix is singular" or returned an inaccurate inverse that changed the estimates.

The test is on `xs`, not on X'X, because the rcond of the raw X'X depends on the covariates' units:
two columns whose scales differ by a factor s give an rcond of about 1/s^2. A test on the raw X'X
treats a full-rank fit with one covariate in large units (GDP in dollars, x 1e8) as singular, and
`pinv()` then zeroes the small-scale covariate. The first version of this guard did that (reviewer
STOP, fixed as C5b); keep any new trigger unit-free.

### Shared collector loop (R/boot.R)

The serial path only fills `boot.out[[j]] <- one.nonpara(boot.seq[j])` in order (RNG use as
before); one loop after the `if (do_parallel_boot)` block stores every replicate for both paths.
Each replicate is stored inside `tryCatch`; if a result cannot be stored (odd shape), the replicate
is replaced by `make_boot_na()` and stored again (a second failure is a bug and re-raises). All
slots are written by index (`colnames.boot`, `eff.off.boot` are preallocated lists), so a replicate
can be rewritten safely. Add any new per-replicate slot inside this loop.

### Implied weights (`wgt.implied`)

`.fect_nt_implied_weights()` computes `ginv(t(Lco)) %*% t(Ltr)` = `Lco (Lco'Lco)^-1 Ltr'` (Xu 2017),
Nco x Ntr; the simplex path stores `t(W_tr)`, also Nco x Ntr. `fect.default()` sets dimnames
(control ids x treated ids). `t(lambda.co) %*% wgt.implied == t(lambda.tr)`; with time fixed
effects the unbounded columns sum to zero (control loadings are centred). NULL when r = 0.

### cfe + never-treated replicates (follow-up B10-cfe)

The point fit of `method = "cfe"` with `time.component.from = "nevertreated"` is
`fect_nevertreated(method = "cfe")`, and so are its parametric refits (`impute_Y0()`). The
nonparametric `one.nonpara()` has a branch for the same case, placed before the plain `cfe` branch,
so case-bootstrap and jackknife replicates, including those inside the `loo` refits, use that
estimator too. The parallel loop's trimmed closure keeps `time.component.from`, which the branch
reads. `dloo = TRUE` with never-treated fitting stops in `fect.default()`'s argument checks, after
the `vartype` and `method` checks and before the bootstrap.

### Cumulative ATT (follow-up B11)

At event time k the cumulative ATT is the running sum of the per-period ATTs (`fit$att`) from the
window's first event time to k. `getEffect()` (so `effect(cumu = TRUE)` and
`estimand("att.cumu", "event.time")`) and `att.cumu.sub()` (so `att.cumu()` with its default
`weighted = FALSE` and `estimand("att.cumu", "overall")`) compute it the same way for the point
estimate and for each replicate. A replicate with no treated cell at one of the window's event times
gives NA and is dropped (`na.rm`) in both, so their bootstrap and parametric SEs agree.
`att.cumu(weighted = TRUE)` keeps the count-weighted number (L times the mean effect over the
window's treated cells) with its old replicate rescaling, identical to 5afa708. Known gap, not
changed here: for jackknife fits `att.cumu()` does not scale the replicate spread by sqrt(N - 1) as
`effect()` does, so their S.E. differ from the second row on.

### Aggregation weights `fit$W.agg` (follow-up B13)

`fect.default()` stores the TT x N aggregation weights as `output$W.agg` only when `W` or `W.agg`
weights the aggregation. Read it with `fit[["W.agg", exact = TRUE]]`: on a fit without the slot,
`fit$W.agg` partially matches the string slot `W.agg.col`. The estimators' own copy of the matrix
sits under the name "W", after the column-name slot of the same name, where extraction by name
cannot reach it; `.po_agg_weights()` falls back to it for fit objects made before the slot existed.

## Architectural Patterns

- **S3 dispatch with a formula interface**: `fect()` and `interFE()` dispatch to formula and default
  methods. The formula methods only parse (through the shared `.fect_formula_names()`) and call
  the default method with column names.
- **R/C++ layering**: numerically heavy steps (SVD, EM, demeaning) live in C++; R handles control
  flow, validation and output assembly. Guards against degenerate input exist on both sides (R rank
  check; C++ `panel_factor()` clamp and the `XXinv()` generalized-inverse fallback, whose trigger
  does not depend on the covariates' units).
- **Method-agnostic pipeline**: `fect.default()` runs one pipeline (validate, reshape, CV, fit,
  bootstrap, diagnostics, assemble); method-specific logic sits in `fect_fe()`, `fect_mc()`,
  `fect_cfe()` and `fect_nevertreated()`.
- **Matrix-oriented data**: panels become `TT x N` matrices and `TT x N x p` covariate arrays early;
  masks (`II`, estimation cells, treated cells) drive every later step.
- **Replicates addressed through a column map**: bootstrap replicates are refits on resampled panels;
  their columns are addressed through `colnames.boot`, never by the original positions. Arrays can be
  wider than N (cluster bootstrap), padded with NA.
- **Fail-soft replicates, loud main fits**: a replicate that fails or returns an odd shape is dropped
  and counted; the same condition in the main fit stops with a message that says what to change.
- **Serial and parallel twins share one collector**: only replicate generation differs between the
  serial loop and the parallel `foreach` / `future` path.
- **Resolved settings are stored on the fit**: `vartype`, `para.error`, `loading.bound`,
  `gamma.loading`, `method` (ife + never-treated reports `"gsynth"`), `remove.id`; post-hoc
  functions read these slots, not `x$call`.
- **Refits inherit the fit's settings**: CV, bootstrap replicates, parametric draws and loo refits
  receive the same `loading.bound`, `time.component.from`, `para.error` and weight roles as the main
  fit.
- **Two-tier post-hoc estimand surface (v2.4.0)**: `imputed_outcomes()` (cell-level long form) and
  `estimand()` (typed dispatcher); `effect()` / `att.cumu()` are soft-deprecated and back
  `estimand("att.cumu")`.
- **Rolling-window CV and the 1-SE rule (v2.3.0)**: default CV design and selection rule;
  `criterion = "pc"` bypasses the rule and picks the lowest PC.
- **Per-role weights (v2.3.1)**: `W.est` (fit) and `W.agg` (aggregation); since this run `W.agg`
  never reaches the fit or the CV scores, and weights reach the parametric bootstrap. The
  follow-up stores the aggregation weights on the fit as `W.agg` (B13).

- `R/polynomial.R` was removed in 2.4.5; the 2026-04-30 version of this file still listed it.
- `dloo` (R/dloo.R, 2.4.7) is a closed-form overlay on the in-sample fit; it is not part of this run's
  changes but uses the reduced covariate set after the rank check.
- Binary (probit) fits do not run on 412d7ae or on this branch (`BiInitialFit()` predicts from a
  NULL model); the binary branches of the rank check and B8e routing are untested end to end.

  for complete panels (never-treated fits such as gsynth when the control panel has no missing
  cell, and `interFE()`). It stops when the absolute change in beta falls below the tolerance. When
  every covariate is in very large units, beta is tiny and the loop stops after one or a few
  iterations, so these estimates can depend on the covariates' units (simgsynth, `Y ~ D + X1`,
  gsynth, r = 2: att.avg 4.8654 with X1, 4.9664 with X1 x 1e8). This predates the run (412d7ae
  gives the same numbers) and is left as is: a relative rule would change the numbers of every such
  covariate fit. `fe_ad_covar_iter()` stops on the relative change of the fit and does not have
  this problem.
- `boot.R` (4,934 lines), `plot.R` (5,312) and `default.R` (4,121) remain the largest files; the
